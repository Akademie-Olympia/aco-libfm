# libfm – das Verhalten hinter PCManFM

libfm ist die Bibliothek, die PCManFM mit Dateioperationen, Papierkorb, Miniaturbildern und „Öffnen mit" versorgt.
`libfm.conf` legt fest, **wie sich Dateimanager verhalten**; das Aussehen steuern
[pcmanfm](https://aco-pcmanfm.readthedocs.io/en/latest/) und [GTK](https://aco-gtk3.readthedocs.io/en/latest/).

:::{note}
Die Datei trägt den Kopf „Autogenerated file, don't edit". Das stammt von libfm selbst und gilt für **die Programmoberfläche**:
Ändert man Einstellungen im PCManFM-Dialog, schreibt libfm die Datei neu. Du kannst sie ebenso von Hand bearbeiten – tu das aber
bei geschlossenem Dateimanager.
:::

## Wichtige Einstellungen

| Schlüssel | Wert | Wirkung |
| --- | --- | --- |
| `single_click` | `0` | Doppelklick öffnet (kein Einfachklick) |
| `use_trash` | `1` | Löschen verschiebt in den Papierkorb |
| `confirm_del` | `1` | Endgültiges Löschen verlangt Bestätigung |
| `confirm_trash` | `0` | Papierkorb-Verschieben ohne Rückfrage |
| `no_usb_trash` | `1` | Auf USB-Datenträgern kein Papierkorb (kein `.Trash`-Ordner) |
| `quick_exec` | `1` | Ausführbare Dateien starten ohne Rückfrage |
| `terminal` | `kitty` | Programme mit Terminalbedarf öffnen in Kitty |
| `si_unit` | `0` | Größen in 1024er-Schritten (KiB), nicht 1000 |
| `thumbnail_max` | `2048` | Miniaturbilder bis 2 MB Dateigröße |
| `show_thumbnail` / `thumbnail_size` | `1` / `128` | Vorschaubilder, 128 px |
| `force_startup_notify` | `1` | Startanzeige beim Öffnen von Programmen |
| `smart_desktop_autodrop` | `1` | Ablegen auf Programm-Symbolen startet es mit der Datei |

Symbolgrößen: `big_icon_size=48` (Symbolansicht), `small_icon_size=24` (Liste), `pane_icon_size=24` (Seitenleiste).

## Seitenleiste („Orte")

Der Abschnitt `[places]` bestimmt, was links erscheint: Home, Desktop, Papierkorb, Anwendungen und nicht eingehängte Datenträger sind **an**;
Dateisystem-Wurzel (`places_root`), Computer und Netzwerk sind **aus**.

## Typische Änderungen

```ini
# ~/.config/libfm/libfm.conf
single_click=1          # Einfachklick öffnet
terminal=foot           # anderes Terminal
confirm_trash=1         # auch beim Papierkorb fragen
places_root=1           # „/" in der Seitenleiste
```

## Fehlersuche

- **Änderung verschwindet:** PCManFM war offen und hat die Datei beim Beenden überschrieben – erst schließen, dann bearbeiten.
- **Keine Vorschaubilder:** `show_thumbnail=1`; für Videos braucht es `ffmpegthumbnailer`.
- **Falsches Terminal:** `terminal=` anpassen; sonst nimmt „Im Terminal ausführen" Kitty.

## Anpassen und zurücksetzen

`~/.config/libfm` ist ein Link auf deine bearbeitbare Kopie unter
`~/.local/share/arch-dotfiles/config/libfm/`. Dort kannst du alles ändern; `pacman -Syu` überschreibt
deine Änderungen **nicht**. Bringt ein Update neue Vorgaben mit, landen sie als `.pacnew`-Datei neben deiner
Version, und du übernimmst, was du willst (`aco sync` führt zusammen, `aco status` zeigt den Zustand).
Zurück zu den Vorgaben: `aco deactivate libfm` stellt die früheren Einstellungen wieder her,
`aco install libfm` aktiviert die Paketvorgaben erneut.
